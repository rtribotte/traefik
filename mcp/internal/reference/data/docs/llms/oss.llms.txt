# Traefik OSS configuration reference

> Machine readable configuration surface for Traefik v3.7.0. Per concept Markdown pages with rich frontmatter, plus a parallel JSON Schema. Generated from the Go source at https://github.com/traefik/reference.

## Routers, services, TLS

Top level dynamic configuration types.

- [http.routers](https://raw.githubusercontent.com/traefik/reference/main/reference/oss/http/routers.md): Router. Router holds the router configuration.
- [http.services](https://raw.githubusercontent.com/traefik/reference/main/reference/oss/http/services.md): Service. Service holds a service configuration (can only be of one type at the same time).
- [tcp.routers](https://raw.githubusercontent.com/traefik/reference/main/reference/oss/tcp/routers.md): TCPRouter. TCPRouter holds the router configuration.
- [tcp.services](https://raw.githubusercontent.com/traefik/reference/main/reference/oss/tcp/services.md): TCPService. TCPService holds a tcp service configuration (can only be of one type at the same time).
- [tls](https://raw.githubusercontent.com/traefik/reference/main/reference/oss/tls.md): TLS. TLSConfiguration contains all the configuration parameters of a TLS connection.
- [udp.routers](https://raw.githubusercontent.com/traefik/reference/main/reference/oss/udp/routers.md): UDPRouter. UDPRouter defines the configuration for an UDP router.
- [udp.services](https://raw.githubusercontent.com/traefik/reference/main/reference/oss/udp/services.md): UDPService. UDPService defines the configuration for a UDP service. All fields are mutually exclusive.
